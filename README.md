# Pizza-Sales-SQL-Analysis
SQL project analyzing pizza sales data using MySQL

**The dataset contains four CSV files**:
- orders.csv
- order_details.csv
- pizzas.csv
- pizza_types.csv

These files were used to create tables and perform analysis using SQL.

 **Pizza Sales SQL Analysis**

This project analyzes pizza sales data using SQL to extract meaningful business insights.

 **Dataset Overview**
The dataset includes information about orders, order details, pizzas, and pizza categories.

 **Analysis Performed**
- Basic analysis: total orders, revenue, top pizzas
- Intermediate analysis: category-wise sales, hourly distribution
- Advanced analysis: cumulative revenue, revenue contribution, ranking using window functions

 **Tools Used**
- MySQL
- MySQL Workbench

 **Project Structure**
- 01_schema_creation.sql
- 02_basic_analysis.sql
- 03_intermediate_analysis.sql
- 04_advanced_analysis.sql
